# Reco Trainer 0.25.1 — Model Hub Sharing Switched On

Videos, frames, labels, checkpoints, and metrics remain entirely on the local computer. Ready for real-world use; not yet bug-free - please report problems.

## Model Hub

- The hub repository [wendibus/reco-models](https://github.com/wendibus/reco-models) is online, and the **Share in hub** button is now available for models you trained yourself.
- **The hub is still empty, and no model has been shared through real GitHub yet.** The first uploads may hit problems, so please report them.
- Sharing asks you to log in to GitHub with a code. The trainer requests the `public_repo` permission for the fork and the pull request, and does not store the login. Everything you share is public and permanent, and you confirm that you have the rights to it.
